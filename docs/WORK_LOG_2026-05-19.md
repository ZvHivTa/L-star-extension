## 新增 Two-Sided L* 实验 learner

新增文件：

```text
two_sided_learner.py
```

该 learner 使用双边观察表：

```text
T[middle, left, suffix] = MQ(left + middle + suffix)
```

集合初始化为：

```text
I = {ε}
P = {ε}
S = {ε}
```

当前版本实现了：

- 双边 closedness：检查 `IΣ ∪ ΣI` 的 boundary rows。
- 右侧 acceptor：使用右转移构造用于 EQ 的 DFA。
- 双边 DOT 输出：右转移用黑色，左转移用蓝色。
- RS 风格反例处理：
  - 从右侧提取 suffix 加入 `S`。
  - 从左侧提取 prefix 加入 `P`。
- 独立 debug 目录：

```text
debug_snapshots_two_sided/
```

该版本暂时没有 monoid consistency check。它用于验证双边状态扩张思路，不声称已经学习到 syntactic monoid。

## 后续理论方向

今天讨论中形成的下一步候选方向：

```text
Monoid-closedness:
  IΣ ∪ II closed

Generator two-sided consistency:
  row(u)=row(v) => row(au)=row(av), row(ua)=row(va)

Recognition:
  EQ passed
```

如果停止时能证明 row 等价对左右字母生成元稳定，则有希望进一步证明 row 等价就是 syntactic congruence。核心问题不再是 row 是否可能“太细”，因为 row 不同已经有真实 `p,s` witness；真正需要排除的是 `P/S` 不足导致的错误合并。
